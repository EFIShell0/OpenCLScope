# OpenCLScope 0.6.0 UI/chrome parity audit

## Reference and permitted differences
- Immutable UI/build reference: VulkanScope 3.0.12.
- Permitted differences: OpenCL API semantics/content, `com.efishell.openclscope` identity, OpenCL branding, monochrome-white OpenCL logo geometry and green accent palette.
- Build/dependency versions remain exactly those of VulkanScope 3.0.12; no upgrade or downgrade is permitted in this release.

## Defects found before patching
- OpenCLScope 0.5.0 still had simplified/duplicate header and bottom-navigation implementations alongside the parity implementation.
- Transient internet/update/collection overlays did not feed their measured height back into page content, so long banners could overlap the first rows.
- Network state was visible but not consistently used as the same validated-internet action gate for Database/update actions.
- Collection status lacked the reference wavy progress treatment.
- Generic TextButton calls did not all pass through the same reference 18 dp/24 dp expressive shape policy.
- Common drawable identity was not locked by a complete reference digest set.

## Patch
- Single frosted header and compact bottom-navigation path with 310/54/42 dp portrait and 340/46/35 dp landscape geometry; 150/180/120 ms selection motion.
- Header logo 126x30 dp; 36 dp back button in a 50 dp slot; 50 dp settings button and the same enter/exit timing.
- Settings card order is Info → Reports & Database → Runtime & Update Preferences with 260 ms + index×45 ms entrance and 120 ms exit.
- Page transitions use directional one-fifth-width spring slide/fade. Scroll-boundary indicators retain 1050/900 ms behavior.
- Collection/network/update banners use the reference 520 dp maximum width, 22 dp shape, surface/border/shadow geometry and transition timing. Validated-network transitions remain visible 4.5 seconds; persistent offline state appears after 380 ms.
- Overlay height is measured and injected into scroll content so banners do not cover the page. Database/update internet actions use the same Android validated-network state.
- Button, outlined button, text button, dialog and switch wrappers apply the same reference geometry; only the accent family is green.
- The 92 common VulkanScope drawable resources are locked byte-for-byte in `VULKANSCOPE_3_0_12_DRAWABLE_REFERENCE_SHA256.json`.

## Evidence gates
- `python -B tools/test_ui_parity.py`: 92/92 common drawables, geometry/timing tokens, network banner behavior, measured overlay inset and deliberate 4.5→4.0 second negative mutation.
- `python -B tools/verify_release.py`: logo, build chain, Analysis, Encyclopedia, licenses, File Manager, D-pad/TalkBack/RTL/reduced-motion and UI parity gates.
- `python -B tools/test_native.py`: OpenCL loader/query/safety bounds and explicit unavailable/error behavior.
- `python -B tools/test_database_contract.py ../OpenCLScope-Database-0.5.0`: producer/Worker schema and exact query contract.
- Database: `python -B tools/verify_release.py`, Worker 7/7 and snapshot 4/4 tests.
- Kotlin parser pass: standalone `kotlinc` reports no syntax/expecting/redeclaration diagnostics; Android/Compose symbols cannot resolve without Android classpath.

## Not executed
- Full AGP compilation/APK packaging: Gradle 9.7.1 distribution is not locally cached and this environment cannot resolve `services.gradle.org`.
- Physical/emulated Android, Android TV D-pad, TalkBack, RTL, high-font/high-DPI visual/device testing.
- Production Cloudflare/GitHub deployment.
