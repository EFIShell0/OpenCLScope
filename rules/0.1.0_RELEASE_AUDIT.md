## Evidence classes

- Source registry parse and C++ catalog regeneration: **PASS** (8 platform, 120 device query definitions; 156 registered reference extensions).
- Host compiler: **PASS** using C++20 and `-Wall -Wextra -Werror` with available JDK JNI headers.
- Behavioral native tests: **PASS**, including absent loader, complete mock enumeration, exact extension names, Unicode, image formats, no-platform and missing-entry-point states.
- Negative mutation: **PASS**, changing `CL_PLATFORM_NOT_FOUND_KHR` handling causes its expected gate to fail; normal loader behavior remains a valid false-positive control.
- XML resource parse, missing R.drawable references, package identity, lack of Internet permission and ZIP clean-extraction integrity: checked by package verification script.
- Android Gradle compile, lint, APK installation, native Android ABI runtime checks, real GPU OpenCL execution, display/TV and animation device checks: **NOT EXECUTED** because an Android SDK/NDK and a test device are unavailable in this execution environment.
- No database implementation by explicit request. Image-format queries are only executed when the vendor implementation exposes image support and context creation functions. Missing `libOpenCL.so` or inaccessible vendor namespace is surfaced as unavailable, not as GPU failure.

## Bounded coverage and known differences

This initial standalone caps viewer performs 8 platform and 120 device property queries by explicit, XML-verified type mapping, plus live extension enumeration and up to 18 image-format class/access combinations per selected device. Its separate local capability checklist is informational, not official OpenCL conformance certification. It does not perform a synthetic compute workload, import/manage vendor OpenCL loaders, create a database, inspect Vulkan surfaces, install Turnip drivers or claim API features not exposed by the live runtime. Thus it follows the supplied visual and quality direction but does not claim binary/feature-for-feature equivalence with Vulkan-only screens.
