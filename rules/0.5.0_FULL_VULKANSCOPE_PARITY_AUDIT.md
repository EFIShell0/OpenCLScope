# OpenCLScope 0.5.0 full VulkanScope parity audit

Reference: immutable VulkanScope 3.0.12 source archive and its `rules/PROJECT_RULES.md`.

## Intentional differences
- Package/application identity: `com.efishell.openclscope` / OpenCLScope.
- API semantics: OpenCL runtime/platform/device/extension/property/image-format evidence replaces Vulkan-only concepts.
- Accent palette: OpenCL green replaces Vulkan red.
- Brand mark: OpenCL geometry plus the exact inherited SCOPE wordmark/layout; all visible mark geometry is white.

## Restored common parity
- VulkanScope build-chain versions are copied exactly: compile/target/min SDK, AGP, Kotlin plugin, Gradle, NDK, ABI filters and dependency versions.
- Compact bottom-navigation dimensions, indicator sizes and selection motion match the reference values.
- Material 3 Expressive shape radii and LTR-content typography policy match the reference.
- Scroll-boundary up/down indicators are installed on the common lazy-page shell and the standalone history/watch/minimum/update pages.
- D-pad directional/page navigation, long OK/Enter copy dialog, TalkBack headings/click labels, RTL and scaled text behavior are preserved.
- Settings includes Info, Reports & Database, runtime/update controls, Obtainium, opening-animation control and File Manager.
- Info exposes packaged libraries and licenses.
- Analysis workspace exposes the same 15 top-level tools; Vulkan-only Presentation/Drivers semantics are replaced by explicit OpenCL counterparts instead of fabricated support.
- Encyclopedia is expanded from a small enum view to generated command/type/token/extension reference coverage from the bundled `cl.xml`.
- Direct update flow downloads only after explicit confirmation, enforces a 256 MiB bound and verifies package identity, signing certificate and newer version before installation is offered.
- Shared-storage File Manager is explicit-user-action-only and bounded.

## Runtime evidence limitations
- Android APK compilation, physical OpenCL runtimes, TV remote, TalkBack, RTL screenshot comparison, font-scale extremes and high-DPI rendering are NOT EXECUTED in this container unless a corresponding build/runtime log is produced.
